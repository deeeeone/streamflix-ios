# StreamFlix for iOS

Sideloadable builds of the StreamFlix iPhone app. Points at `watch.streamflix.one` (site) and `api.streamflix.one` (API).

## Install

Download the latest `StreamFlix.ipa` from [Releases](../../releases/latest) and sideload it with **AltStore**, **Sideloadly**, or your preferred signing tool (free Apple IDs work; the app is re-signed on your device).

Direct download of the latest IPA:
```
https://github.com/deeeeone/streamflix-ios/releases/latest/download/StreamFlix.ipa
```

Requires iOS 17+.
